문제 발생 시 복구

행사 버튼이 꺼져 있으면 준비 목록의 부족한 메뉴·수량과 정답 2개 조건을 확인하세요. 일반 주문 판매 후 재고가 줄 수 있어요. 준비 완료를 눌렀어도 시작 직전 재고가 부족하면 다시 준비 화면으로 돌아가요.

  1. 진행을 멈추고 오류 문구를 확인해요. 저장을 지우거나 새 카페를 만들지 마세요.
  2. 같은 주소·같은 브라우저에서 다시 열어 이어하기를 확인해요. 다른 카페가 열려 있으면 1·2호점을 확인해요.
  3. 다른 탭에서 변경됐다는 안내면 중복 탭을 닫고 최신 저장을 다시 불러와요.
  4. 저장 공간 오류면 현재 화면을 유지하고 가능한 경우 JSON 백업을 먼저 받으세요. 사이트 저장 삭제부터 하지 마세요.
  5. 복구가 필요하면 테스트판의 현재 저장도 백업한 뒤 마지막 정상 JSON을 가져와요. 가져오기 전 레벨·돈·직원·과목을 확인하세요.
  6. 백업도 없고 브라우저 데이터가 삭제됐다면 복구할 서버 계정이 없어요. 교사에게 상황을 알려주세요.

특별 영업 실패에는 별도 벌금이 없어요. 다음 영업 전에 다시 예약할 수 있어요. 학습 기록과 기존 성장은 유지돼요.
