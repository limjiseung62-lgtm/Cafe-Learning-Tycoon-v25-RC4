카페 v2.5 RC4 · 15분 체험 안내

로그인이나 실명 입력 없이 시작해요. 아직 정식판이 아닌 테스트 후보예요.

  1. 내 카페 키우기를 선택해요. 새 카페를 만들거나 기존 카페 JSON 백업을 가져와요.
  2. 1·2호점 중 운영할 카페와 오늘 공부할 수학·국어 문제팩을 선택해요.
  3. 빠른 서비스·정성 서비스·단체 주문 중 전략을 고르고 15분 영업을 시작해요.
  4. 음식 만들기에서 문제를 풀어요. 직원이 없으면 준비된 음식을 서빙하기로 전달해요.
  5. 특별 영업을 예약했다면 준비 화면에서 필요한 메뉴별 현재/필요 수량과 부족 수량을 확인해요. 문제 2개를 맞히고 모든 예약 메뉴 재고를 채우면 손님 맞이 버튼이 켜져요. 예약에 필요한 음식은 모으는 동안 일반 주문에 쓰지 않고 보관하며, 초과분은 판매해요. 준비 버튼은 재고를 빼지 않아요. 실제 음식 준비 때 한 번만 차감해요. 판매로 재고가 바뀌면 준비 상태도 바뀌므로 다시 확인하세요. VIP는 응용 정답으로 특별 메뉴를 만들며 일반 음식 재고를 쓰지 않아요. 근무 직원 0명일 때 목표 1팀·행사 최대 5분·예약 손님 대기 90초 추가·예약 먼저 수동서빙을 적용해요. 1명 이상은 최대 3분 30초예요. 남은 영업시간이 짧으면 일찍 끝나요.
  6. 영업 뒤 학습 결과·복습지·정답해설을 확인하고 JSON 백업을 저장해요.
  7. 다시 접속해 카페가 이어지는지 확인해요.

기존 카페 가져오기

공식판의 내 카페 키우기 → 기록 → JSON 백업으로 파일을 받은 다음 테스트판의 기록 → 가져오기에서 선택하고 확인해요. 기존 테스트 저장이 있으면 먼저 백업하세요. 가져오기는 테스트판 현재 카페를 교체하므로 내용을 확인하세요. 공식판에 테스트 백업을 역으로 가져오지 마세요.

공식판·RC2·RC3와 RC4 테스트판은 별도 저장이에요. 이전 테스트 카페도 JSON 백업을 받은 뒤 RC4에 직접 가져오세요. 다른 주소·다른 기기로 자동 이전되지 않아요. 브라우저 데이터를 지우거나 기기를 바꾸면 JSON 백업 없이는 복구할 수 없어요. 비밀 모드 사용을 피하세요.
